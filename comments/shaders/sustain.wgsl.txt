// Merlin's sustains, one invocation per frame.
//
// A sustain is a voice with no note-off, unit gain and no filter, so every frame
// of it is a pure function of its frame number: position by multiplying, loops
// by modulo, the envelope and the tremolo in closed form. `render.wgsl` walks a
// voice's frames one after another, so a key's time there is its longest note's.
// Here it is its frames over the card's width.
//
// One workgroup per page of a job. The host works out where each page starts,
// in 128-bit arithmetic, so this needs no 64-bit integers: a frame is at most
// `PAGE` steps from its page's start, which fits in what WGSL multiplies.
//
// Only what is a pure function of the frame comes here. A waveform whose pitch
// moves (a pitch LFO, a glide, a modulation envelope) keeps the voice path. See
// `gpubuild::direct_ok`.
