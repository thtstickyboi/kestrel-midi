//! Bytes in and bytes out, for the state a single render saves when it stops:
//! `Enc` writes plain little-endian values, `Dec` reads them back and says so
//! when the bytes run out.
//!
//! **Why not serde.** A snapshot holds floats that must come back as the same
//! bits (`f32::to_bits`, never a text round trip), arrays a few hundred entries
//! long, and a handful of vectors that run to megabytes. Writing each field by
//! name in one place, next to the struct it belongs to, is also what lets a
//! test say "every field is here": see the exhaustive destructuring in
//! `Driver::save_state`, which stops compiling when a field is added without
//! being decided on.
//!
//! Every length is written before what it counts, and every read of a counted
//! thing checks the count against what the receiver expects, so a snapshot made
//! under another configuration is refused rather than half read.
