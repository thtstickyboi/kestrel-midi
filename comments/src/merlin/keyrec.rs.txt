//! What merlin's key parser (`keyparse`) needs to turn a paired note into the
//! records key-major renders: each channel's state as the stream stands at an
//! event ([`Channels`]), and a note's layers built as the driver builds them
//! ([`Layers`]).
//!
//! **The state is read where the event sits, not by tile.** The driver
//! publishes channel state in rows at gate tiles, with a bit to say a note on
//! a controller's own tick reads the next row; a note-off's gain is read from
//! its tile's row, and a CC120 cut from whether a cut is in that tile. Merlin
//! does not follow it there: a note takes the channel as it stands at its
//! note-on, its release tail the channel as it stands at its release, and a
//! note is cut when a CC120 released it. Where no controller moves within a
//! tile the two agree to the bit, which is what the digest checks.
//!
//! **Restated here, exactly:** presets (programs, CC0, the GS drum part and
//! resets), channel gain (CC7, CC10, CC11, CC67 and their fine halves, as
//! `Driver::refresh_gain` folds them) and the pitch the channel adds (bend,
//! RPN 0-2, as `Driver::refresh_bend` sums it, then merlin's bend grid as the
//! bucket pass applies it). **Built by the driver's own code:** the layers,
//! `PreviewMemo::preview`, `Bank::build_layer` and `Driver::make_cmd`, and
//! the sound controllers' params tables, `Bank::build_variant`.
//!
//! **A params variant is built from the raw CC71-75 values a note is struck
//! under**, one table per distinct set. The driver keys its variants by the
//! values quantised, builds each from whichever raw values first asked for it,
//! and past `max_param_variants` rebuilds or falls back; so its params depend
//! on the file's history, and merlin's on the note. They agree wherever each
//! quantised set only ever had one raw set behind it.
//!
//! **Not yet, and flagged when a file needs it** ([`unsupported`]):
//! portamento, the modulation LFOs, MIDI tuning, analytic phase, and banks
//! with random regions (whose draw the driver seeds from a note id counted
//! over every key).
