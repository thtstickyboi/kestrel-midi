    /// Ceiling on how much of the pool one block may steal, in percent.
    ///
    /// Without this, a block whose note-ons outnumber the pool steals *every*
    /// voice and refills every slot, so each block opens with the whole pool at

    /// Ramp channel gain across a gate tile instead of stepping it.
    ///

    /// applied as a step, so an abrupt CC7/CC11 move put a hard amplitude

    /// Ramping spreads that change over `gate_frames` (0.67 ms at the

    /// than the discontinuity. It never touches a voice's own attack: the

    /// voice's first tile is always set directly.
    ///
