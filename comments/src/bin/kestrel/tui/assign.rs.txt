//! Which soundfonts each file of a batch gets: a table driven with the arrow
//! keys, in the terminal.
//!
//! A row is a file to write. The arrow keys move between rows, Space marks them,
//! and Enter gives the marked rows (or the one under the cursor) soundfonts, which
//! opens the system's file picker or offers a set already picked. Nothing is
//! typed. The keys are shown on the screen.
//!
//! The state is a plain struct (`Table`) that turns a key into what to do next,
//! so it is checked without a terminal; drawing and reading keys are separate.
