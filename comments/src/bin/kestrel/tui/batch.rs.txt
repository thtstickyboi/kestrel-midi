//! The guided renderer's batch: several MIDIs, each with the soundfonts it is
//! given, or one MIDI on several sets.
//!
//! A front end and nothing more, like the rest of the guided renderer. The jobs
//! it builds go through `kestrel::batch` -- the same planning and the same
//! runner `kestrel render a.mid b.mid` and `kestrel batch` use -- so a file
//! written here is the file the equivalent command writes.
//!
//! Which soundfonts each file gets is the arrow-key table in `assign`. The only
//! windows this opens are the system's file pickers.
