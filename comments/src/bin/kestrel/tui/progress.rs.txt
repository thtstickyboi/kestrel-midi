/// The stop a key asks for, if it asks for one. Either takes a second press to
/// act, see `CONFIRM`; this only says which.
///
/// Ctrl+C and Esc stop and keep. **Ctrl+D** stops and discards, the same on every
/// system: raw mode takes it as a key and not as the end of input. (Ctrl+Shift+C,
/// which was tried, never arrives: Windows Terminal keeps it for Copy.) Ctrl+D is
/// only meant when the render has progress to keep (`saving`); a render that has
/// none has one kind of stop. Either is a press in the same terms as the other,
/// so a Ctrl+D can arm the stop as a Ctrl+C does. Caps Lock or Shift makes the
/// letter a capital, and does not change which key it is.
