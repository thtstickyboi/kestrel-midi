//! Whether a newer Kestrel has been released: one request to GitHub's releases
//! API, and a notice. Nothing is downloaded and nothing is installed -- the
//! person follows the link and downloads the release themselves.
//!
//! That is also why a check costs nothing in the release's download counts.
//! GitHub counts fetches of an asset file, and this reads only the release's
//! description, so every count on the release page is still a person who
//! downloaded it.
//!
//! The request carries no identifier and nothing about the machine: GitHub
//! sees an address and a `kestrel/<version>` user agent, and Kestrel sees the
//! latest release's tag.
//!
//! Which releases are announced is the person's update ring, chosen in Extras
//! and kept in `ktrl.ini`: fast is every release, slow is feature releases
//! only. `KESTREL_NO_UPDATE_CHECK` turns the check off.
