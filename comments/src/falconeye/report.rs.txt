//! The machine report: one file a user can send, holding what it takes to
//! chase a problem on a machine nobody here can reach.
//!
//! Asked for by the user 2026-09-26: "profile everything from the machine to
//! report, that the user can send to me". It collects a fixed list, not
//! "everything accessible".
//! What is in it is said in [`HEADER`], before anything is collected, and
//! what is left out as well: files, other programs' names, network details,
//! serial numbers, environment variables.
//!
//! Every line goes through [`Redactor`]: the PC's and the account's names
//! become `<pc>` and `<user>`; the MIDIs', soundfonts' and tracks' names are
//! kept. The result is `kestrel-report-<time>.zip`, holding `report.txt` to
//! read, `report.json` for tooling, and the recent render logs and
//! FalconEye reports.
